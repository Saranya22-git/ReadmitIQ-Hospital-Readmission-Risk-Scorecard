# Power BI Dashboard — Hospital Readmission Risk Scorecard

## Overview

This folder contains instructions to build the ReadmitIQ Power BI dashboard
using the CSV dataset generated by the ML pipeline.

---

## Dataset

**File:** `data/hospital_readmission.csv`
**Records:** 5,000 patients
**Columns:** 15 features + 1 target (`readmitted_30d`)

---

## Step-by-Step: Build the Dashboard

### Step 1 — Import Data

1. Open **Power BI Desktop**
2. Click **Get Data → Text/CSV**
3. Select `data/hospital_readmission.csv`
4. Click **Transform Data** to open Power Query Editor

### Step 2 — Data Transformations in Power Query

Apply these transformations:

| Column | Action |
|--------|--------|
| `readmitted_30d` | Change type to **Text**, replace `1` → `"Yes"`, `0` → `"No"` |
| `diabetes`, `hypertension`, `heart_failure`, `copd` | Change type to **Text**, replace `1` → `"Yes"`, `0` → `"No"` |
| `age` | Keep as **Whole Number** |
| `length_of_stay` | Keep as **Whole Number** |

**Add a Custom Column** — Age Band:
```
= if [age] <= 30 then "18–30"
  else if [age] <= 40 then "31–40"
  else if [age] <= 50 then "41–50"
  else if [age] <= 60 then "51–60"
  else if [age] <= 70 then "61–70"
  else if [age] <= 80 then "71–80"
  else "81+"
```

Click **Close & Apply**.

---

### Step 3 — DAX Measures

Create these measures in the **Modeling** tab:

```dax
-- Total Patients
Total Patients = COUNTROWS(hospital_readmission)

-- Total Readmitted
Total Readmitted = CALCULATE(COUNTROWS(hospital_readmission), hospital_readmission[readmitted_30d] = "Yes")

-- Readmission Rate
Readmission Rate % = DIVIDE([Total Readmitted], [Total Patients]) * 100

-- Average Length of Stay
Avg LOS = AVERAGE(hospital_readmission[length_of_stay])

-- Avg Medications
Avg Medications = AVERAGE(hospital_readmission[num_medications])

-- High Risk Count (3+ prior admissions AND 2+ comorbidities)
High Risk Count =
CALCULATE(
    COUNTROWS(hospital_readmission),
    hospital_readmission[num_prev_admissions] >= 3
)
```

### Step 4 — Dashboard Pages

Build **3 report pages**:

#### Page 1: Executive Summary
| Visual | Type | Fields |
|--------|------|--------|
| Total Patients | Card | `Total Patients` |
| Readmission Rate | Card | `Readmission Rate %` |
| Avg Length of Stay | Card | `Avg LOS` |
| High Risk Count | Card | `High Risk Count` |
| Readmission Rate by Department | Bar Chart | Axis: `department`, Value: `Readmission Rate %` |
| Readmission Split | Donut Chart | Legend: `readmitted_30d`, Values: Count |
| Department Slicer | Slicer | `department` |
| Insurance Slicer | Slicer | `insurance_type` |

#### Page 2: Patient Demographics
| Visual | Type | Fields |
|--------|------|--------|
| Age Band Distribution | Column Chart | Axis: `Age Band`, Values: Count |
| Readmission Rate by Age Band | Line Chart | Axis: `Age Band`, Values: `Readmission Rate %` |
| Gender Split | Pie Chart | Legend: `gender`, Values: Count |
| Comorbidity Flags | Stacked Bar | `diabetes`, `hypertension`, `heart_failure`, `copd` |
| Insurance Breakdown | Bar Chart | Axis: `insurance_type`, Values: `Readmission Rate %` |

#### Page 3: Clinical Risk Drilldown
| Visual | Type | Fields |
|--------|------|--------|
| Discharge Disposition Risk | Bar Chart | Axis: `discharge_disposition`, Values: `Readmission Rate %` |
| Avg Medications by Department | Column Chart | |
| Prior Admissions Histogram | Column Chart | Axis: `num_prev_admissions`, Values: Count |
| Matrix: Dept × Insurance | Matrix | Rows: `department`, Columns: `insurance_type`, Values: `Readmission Rate %` |
| LOS vs Readmission | Scatter Chart | X: `length_of_stay`, Y: `num_medications`, Legend: `readmitted_30d` |

---

### Step 5 — Formatting Tips

- **Theme:** Dark background (`#0d1117`), white text — matches the ReadmitIQ website
- **Accent color:** `#e05c5c` (red) for high-risk values
- **Font:** Segoe UI throughout
- **Conditional formatting:** Apply red→green color scale on readmission rate columns
- Add **"ReadmitIQ"** as report title with the cross icon

---

### Step 6 — Export

1. **Save as:** `ReadmitIQ_Dashboard.pbix`
2. **Export PDF:** File → Export → PDF (for GitHub)
3. **Take screenshots** and save to `powerbi/screenshots/`
